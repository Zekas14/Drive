## 🎯 Overview
**Drive App** is a backend-only **ride management REST API** built with **ASP.NET Core**.

The project focuses on secure authentication and clean backend structure using
**Controllers**, **Services**, and the **Repository Pattern**.

---

## 🚗 Features
- User registration & login
- JWT-based authentication
- Trip creation
- Trip acceptance & cancellation
- Secured RESTful endpoints

---

## 🔐 Authentication
- ASP.NET Identity
- JWT (Bearer Token)
- `[Authorize]` protected endpoints

---

## 🗃 Data Access
- Entity Framework Core
- Repository Pattern
- Async database operations
